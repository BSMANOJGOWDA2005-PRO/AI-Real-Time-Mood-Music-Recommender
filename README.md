# 🎵 ChronoTune AI – Real-Time Mood Music Recommender

## 📌 Overview

ChronoTune AI is an AI-powered web application that detects a user's facial emotion in real time using the webcam and recommends songs based on the detected mood. The application supports multiple login methods, language preferences, YouTube & Spotify recommendations, premium subscriptions, and play history.

# ⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/ChronoTune-AI.git
```

2. Open the project folder.

3. Open **index.html** in your browser.

4. Allow camera permission.

5. Enjoy AI-powered mood-based music recommendations.
